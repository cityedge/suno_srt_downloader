Suno SRT Downloader v1.2.0

ブックマークレットをクリックすると小さなダイアログが開き、開始補正だけを選んで「ダウンロード」できます。その他の補正は固定です。

Click the bookmarklet to choose only the start offset in a small dialog, then download the adjusted SRT. All other corrections remain fixed.

下のボタンをブックマークバーへドラッグしてください
Drag the button below to your bookmarks bar.

Suno → SRT

ブックマークバー表示 / Show bookmarks bar: Ctrl+Shift+B

開始補正 / Start offset

起動時のダイアログで 0.0〜-0.5秒を0.1秒刻みで選択できます。初期値は-0.1秒です。選択値は保存され、次回起動時に復元されます。

Choose from 0.0 to -0.5 seconds in 0.1-second steps. The default is -0.1 seconds, and the selected value is remembered for the next run.

自動修復 / Automatic repair

行内の隣接トークン間隔が3.0秒を超える場合、最大の異常間隔を1.5秒へ圧縮します。メタタグ後の最初の歌詞行は開始側を、それ以外は終了側を修復します。このロジックはv1.1.0から変更していません。

When an adjacent-token interval exceeds 3.0 seconds, the largest abnormal interval is compressed to 1.5 seconds. The first lyric after a metadata tag is repaired on the start side; other lines are repaired on the end side. This logic is unchanged from v1.1.0.

重要 / Important

曲の生成後、Suno上で歌詞を編集するとその都度、同期タイミングが再構成されます。タイミングの精度は基本的に再構成のたびに下がります。歌詞を一度も編集していない状態で実行するようにしてください。

After a song is generated, each lyrics edit in Suno rebuilds the synchronization timing. Timing accuracy generally decreases with each rebuild. Run this tool before the lyrics have been edited even once.

使い方

  1. Sunoにログインし、対象曲の /song/... または /edit/... ページを開きます。
  2. ブックマークバーのSuno → SRTをクリックします。
  3. 開始補正を選び、ダウンロードを押します。
  4. 曲名.srtがダウンロードされます。

How to use

  1. Sign in to Suno and open the target /song/... or /edit/... page.
  2. Click Suno → SRT on the bookmarks bar.
  3. Choose the start offset and click Download.
  4. Song title.srt is downloaded.
